# Introdução à Engenharia de Telecomunicações

> Obrigatória, 1º semestre · Bacharelado em Engenharia de Telecomunicações · IFCE Campus Fortaleza

| | |
|---|---|

| **Sigla no horário** | IENGTEL |
| **Carga horária** | 40 h |

| **Pré-requisitos** | Nenhum |

## Ementa

O Instituto Federal e o curso de Engenharia de Telecomunicações. Conceitos Gerais de Engenharia de Telecomunicações. Ensino Pesquisa e Extensão no contexto do curso. Inovação e Empreendedorismo; Conceitos de Projetos de PD&I; Palestras Gerais em tecnologias atuais, dentre outras ligadas à área.
