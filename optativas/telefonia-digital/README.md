## Ementa

Arquitetura do sistema telefônico; Sistemas PCM; A central de comutação; Comutadores digitais; Sinalização telefônica; Planos estruturais; Sistemas de comunicações ópticas; Redes de transporte; Teoria do tráfego; Projeto de sistema telefônico.
