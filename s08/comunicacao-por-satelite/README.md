# Comunicação por Satélite

> Obrigatória, 8º semestre · Bacharelado em Engenharia de Telecomunicações · IFCE Campus Fortaleza

| | |
|---|---|
| **Código** | `01.503.36` |
| **Sigla no horário** | CSAT |
| **Carga horária** | 80 h |
| **Créditos** | 4 |
| **Pré-requisitos** | [Antenas](../../s07/antenas/) |

## Ementa

Histórico da Comunicação via Satélite; Elementos da Comunicação via Satélite; Descrição da Estação Terrena; Enlace via Satélite; Satélites de baixa e média órbita; Sistemas de Satélites para Comunicações Móveis; Sistemas de banda ultra larga (UWB); Modelamento de canal UWB; Antenas para UWB. Tópicos Gerais.
