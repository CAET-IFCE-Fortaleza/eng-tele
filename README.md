# 📡 eng-tele: Engenharia de Telecomunicações · IFCE Fortaleza

Repositório colaborativo de materiais de estudo do **Bacharelado em Engenharia de Telecomunicações do IFCE, Campus Fortaleza**, mantido pelo **CAET** (Centro Acadêmico de Engenharia de Telecomunicações).

Aqui ficam resumos, listas de exercícios, provas antigas (com autorização) e dicas de cada disciplina, organizados por semestre. Tudo é feito por estudantes, para estudantes.

## Como navegar

```
eng-tele/
├── s01/ … s10/          ← disciplinas obrigatórias, por semestre da matriz
│   └── calculo-01/
│       ├── README.md     ← código, carga horária, pré-requisitos, ementa e bibliografia
│       ├── resumos/
│       ├── listas/
│       ├── provas-antigas/
│       └── dicas.md
├── optativas/            ← as 28 optativas
├── tcc-e-estagio/        ← TGI, TCC, estágio e atividades complementares
└── grade/                ← fluxograma de pré-requisitos e horários
```

Os nomes de pasta seguem o padrão `sNN/nome-da-disciplina`, sem acentos, com números no lugar de algarismos romanos (por exemplo, `s04/redes-de-computadores-01`).

## Sobre a matriz

- Matriz curricular **11892 (2018.2)**, em vigor. As 45 disciplinas obrigatórias somam **3.240 h**.
- O portal do IFCE informa uma carga total de **4.080 h** para o curso; a diferença corresponde a componentes como optativas, estágio e atividades complementares. Confira os detalhes no [PPC](https://portal.ifce.edu.br/documents/4747/).
- Documentos oficiais no portal do IFCE: [Matriz curricular](https://portal.ifce.edu.br/documents/4742/) · [PUDs (ementas)](https://portal.ifce.edu.br/documents/14677/) · [PPC](https://portal.ifce.edu.br/documents/4747/) · [Horários 2026.2](https://portal.ifce.edu.br/documents/25402/).

## Como contribuir

Qualquer estudante pode mandar material. O passo a passo (pelo navegador mesmo, sem precisar instalar nada) está no **[guia de contribuição](CONTRIBUTING.md)**.

Resumindo:
1. Escolha a pasta da disciplina.
2. Envie o arquivo pelo botão **Add file → Upload files** do GitHub.
3. Abra um pull request; alguém do CAET revisa e aprova.

Não tem conta no GitHub ou não quer mexer nisso? Mande o material para o CAET que a gente sobe por você.
